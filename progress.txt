DECISIONS
---------
- Reusable Section Architecture: Split Home page into small, focused section components under components/sections/ (hero, skills strip, featured projects, latest posts, closing CTA), each strictly under 150 lines.
- Data Access Layer in services/: Placed all content retrieval behind async service functions in services/ (site, skills, experience, projects) satisfying PRD Section 11 Rule 4 and Section 13 for future AI chatbot context ingestion.
- Polymorphic Button asChild: Extended components/ui/button.tsx with React.cloneElement asChild support to cleanly render Next.js <Link> elements with shadcn cva button styling without invalid nested anchor/button HTML.
- Lucide Brand Icons: Implemented accessible, minimal SVG icon components for GitHub and LinkedIn in components/ui/icons.tsx adhering to Lucide's 24x24 geometry since Lucide v1+ excludes commercial brand logos.
- Motion Accessibility: Wrapped animated sections in a reusable FadeIn component using Framer Motion's useReducedMotion() hook to disable motion transitions for users requesting reduced motion.
- Blog Empty State on Home: Included a graceful empty state in LatestPostsSection per PRD Rules 6 & 10 to keep Home visually complete without implementing Phase 5 blog models or routes early.
- Inline Resume View: Designed an editorial inline CV document view on /resume alongside the PDF download button so recruiters can review credentials instantly even before the static PDF asset is uploaded.
