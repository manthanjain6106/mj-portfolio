DECISIONS
---------
- Admin Route Architecture: Separated authenticated admin routes into app/admin/(authenticated)/ with its own layout verifying requireAdmin(), while placing app/admin/login outside the route group to prevent redirect loops.
- Dual-Layer Security Verification: Guarded admin routes via both Edge middleware.ts (pre-render redirection) and mandatory server-side requireAdmin() session re-checks in all admin layouts and actions per PRD Section 10.
- Strict Email Whitelist: Enforced ADMIN_EMAIL verification directly inside NextAuth's signIn callback to immediately reject any non-whitelisted GitHub account before a session is issued.
- Serverless-Ready Mongoose Cache: Implemented global connection caching with bufferCommands: false in lib/mongodb.ts and hot-reload model re-compilation guards across all models in models/.
- Live Dashboard Empty States: Designed Dashboard metrics cards and recent activity streams to query real database counts and display structured empty states when zero items exist.
- Robots & Crawling Restrictions: Created app/robots.ts disallowing /admin/ and /api/ paths and configured explicit noindex/nofollow robots metadata on app/admin/layout.tsx.
- Clear Environment Guidance: Formatted lib/env.ts to throw formatted terminal alerts pointing directly to .env.local and .env.example if required variables are omitted at runtime.
