DECISIONS
---------
- Server-Side Signed Media Uploads: Enforced authenticated admin session validation and strict MIME type allowlist + 5 MB size limit directly on the server before streaming image buffers to Cloudinary.
- Automatic Cloudinary Asset Cleanup: Deleting a project automatically detects and destroys non-placeholder uploaded images from Cloudinary to avoid orphan assets.
- Draft Seeding Workflow: Created scripts/seed-projects.ts importing seed projects as DRAFTs per user specification, allowing the owner to review, edit, and toggle them to published in the admin UI.
- ISR & Instant Admin Revalidation: Applied export const revalidate = 60 with on-demand revalidatePath in Server Actions so admin updates appear instantly on Home, /projects, and /projects/[slug] without redeploying.
- Comprehensive Resilience: Added loading.tsx and error.tsx boundaries to all public and admin project routes with structured skeleton screens and retry capabilities.
- Admin Route Architecture: Separated authenticated admin routes into app/admin/(authenticated)/ with its own layout verifying requireAdmin(), while placing app/admin/login outside the route group to prevent redirect loops.
- Dual-Layer Security Verification: Guarded admin routes via both Edge middleware.ts (pre-render redirection) and mandatory server-side requireAdmin() session re-checks in all admin layouts and actions per PRD Section 10.
- Strict Email Whitelist: Enforced ADMIN_EMAIL verification directly inside NextAuth's signIn callback to immediately reject any non-whitelisted GitHub account before a session is issued.
- Serverless-Ready Mongoose Cache: Implemented global connection caching with bufferCommands: false in lib/mongodb.ts and hot-reload model re-compilation guards across all models in models/.
